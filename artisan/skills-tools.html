Daily Driver

What's open every day

These don't leave the toolbar. Between them they cover writing, coding, and shipping — nothing here is optional.

AI Coding Agent

Claude Code

My primary AI coding agent — built the automated helpers, ready-made routines, and shortcuts that run my team's workflow, plus this entire portfolio site.

Cu
AI-Native IDE

Cursor

Where most day-to-day feature work and prototype code actually gets written, with AI assistance built into the editing loop.

VS Code

The base editor underneath — extensions, config, and general dev work that doesn't need Cursor's AI layer.

WF
Voice Dictation

Wispr Flow

Voice-to-text for nearly everything I write — specs, messages, emails. Talking is faster than typing, so this runs constantly.

Gh

GitHub

Everything I build gets owned and published here — personal projects, this site, side experiments. Nothing stays local.

Excel / Google Sheets

Where most of my product data analysis happens — cohort cuts and funnel math, before a metric earns a place on a real dashboard.
