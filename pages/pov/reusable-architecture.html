Executive Briefing (2026-03-18)
Separated the briefing (informational — "what happened") from recommendations (actionable — "what to do") into two independent capabilities. The briefing uses a Now Assist Skill for synthesis; recommendations will live in a separate experience. Each capability stands alone and can evolve independently.

Column-Level Filter System (2026-03-21)
Toggle-able filter row for any table-based dashboard — text inputs for free-text search, dropdowns for enum fields. Hidden by default behind a funnel icon, auto-clears when toggled off. Pattern reusable across all workspace dashboards.

Rich Text Notes Editor (2026-03-21)
ContentEditable modal with formatting toolbar (bold, italic, underline, strikethrough, lists, alignment, links). Stores HTML in the notes field, renders previews with 2-line clamp in the list. Reusable component pattern for any workspace page needing rich text input.
